# SUST Transit Requisition

Vehicle requisition and allocation system for SUST Transit.

| Folder | Contents |
| --- | --- |
| `frontend/` | React + TypeScript + Vite web app (currently uses localStorage) |
| `backend/` | Node.js + Express + MySQL API (planned) |
| `docs/` | Requirements and backend implementation plans |

## Quick start

```bash
cd frontend
npm ci
npm run dev
```

See [`frontend/README.md`](frontend/README.md) for scripts and project structure.
