# SUST Transit — Frontend

React 19 + TypeScript + Vite + Tailwind CSS v4. Data is stored in `localStorage` until the backend is ready.

## Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Type-check and build for production |
| `npm run lint` | Run ESLint |
| `npm run preview` | Preview the production build |

## Setup

```bash
npm ci
cp .env.example .env
npm run dev
```
